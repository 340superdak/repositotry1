Zebra ZP 450 Printer

This installs a printer application for the Zebra ZP 450 thermal label printer. Your Mac will see the printer as a standard AirPrint-style device, so it prints from any app's print dialog.

What gets installed

  • The printer software and every library it needs, in /usr/local/zp450
  • A background service that starts at boot
  • A print queue named ZP450

Nothing else on this Mac is modified. No developer tools or Homebrew are required.

Connect the ZP 450 over USB and switch it on before continuing, so the queue can be created automatically. If you forget, you can finish later by running sudo zp450-setup in Terminal.
