Installed

Print a test label from System Settings › Printers & Scanners, or from any app, choosing the ZP450 printer.

Printer settingshttp://localhost:8100/ — media size, darkness, speed
Queue not created?Connect the printer, then run sudo zp450-setup
Blank labels?The printer may speak the other language: sudo zp450-setup --zpl
Remove itsudo zp450-uninstall

Documentation is in /usr/local/zp450/share/doc/zp450.
